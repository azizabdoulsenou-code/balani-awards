# Balani Awards — Personnalités honorées

Site des pages de présentation liées aux codes QR des attestations Balani Awards 2026.

- Données : `people.json` (une entrée par personne, photo `<slug>.jpg` à la racine)
- Génération des pages : `python3 build.py`
- Attestation PDF : `python3 attestation.py <slug>`
